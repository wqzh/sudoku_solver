三步用起来

点「示例题」会生成一张标准数独图，也可以换成你自己的照片。

选图或拍照

相册、相机、拖拽、粘贴都可以，支持倾斜与手持拍摄。

自动定位网格

检测模型找到网格四边形，透视校正成标准 9×9 画布。

识别与求解

逐格切分识别数字，回溯求解；识别有误时用次优候选自动纠错。

答案回贴

只在原本空白的格子里写红色答案，位置随原图透视一起对齐。

和网页版同一套算法

Python 管线逐段移植到 JavaScript，验收标准是与原版逐格一致。

YOLO 网格检测

单类检测器给出网格框，再用线条评分把四边形收紧到最外层网格线上。

自适应二值化

光照归一 + 均值自适应阈值，再擦掉网格线，弱光、阴影下也能稳定切格。

29 候选纠错

先用最优解；无解时用置信度最低的 1–2 个数字换次优类重试，再试 4 个旋转。

不上传照片

ONNX Runtime Web 在本机 WASM 里推理，没有服务端，没有接口调用。

一条完整管线

从像素到答案，每一步都可单独调参数。

1000 px 工作图

等比缩放并补 24 px 白边，避免贴边网格轮廓不闭合。

740 px 校正图

四点到四边形单应变换，9×80 px 单元格 + 10 px 边距。

81 个 28×28 掩膜

白字黑底、0–255 不归一化，与训练时完全一致。

位运算回溯

最少候选优先，节点与时间双上限，最难的盘面也秒解。
